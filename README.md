## 📖 About

Em Fashions is a modern e-commerce fashion store web application offering a seamless shopping experience for clothing and accessories. Built with a focus on performance and elegant UI.

## ✨ Features

- 🛍️ **Product Catalog** — Browse collections with categories & filters
- 🛒 **Shopping Cart** — Add/remove items with real-time updates
- 🔐 **User Accounts** — Sign up, login, and manage orders
- 📱 **Mobile-First Design** — Optimized for all screen sizes
- 💫 **Smooth Animations** — Premium user experience

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | Next.js 14, TypeScript |
| Styling | Tailwind CSS |
| State | React Context / Zustand |
| Deployment | Vercel |

## 🚀 Getting Started

```bash
git clone https://github.com/Itua254/EmFashions.git
cd EmFashions
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
